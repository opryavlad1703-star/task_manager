## 2. Результат виконання
![Результат виконання](screenshot.png)

1. Яке призначення вебсервера (наприклад, Apache) у процесі веброзробки?
Вебсервер приймає HTTP-запити від браузера клієнта, обробляє їх (викликає інтерпретатор PHP для виконання скриптів) і повертає згенеровану HTML-сторінку клієнту.
2. Яким розширенням файлу повинен володіти скрипт, щоб сервер обробив його як PHP-код?
Файл повинен мати розширення .php (наприклад, index.php).
3. Чому PHP-файл потрібно відкривати через браузер за адресою localhost, а не просто подвійним кліком миші у файловому менеджері?
При подвійному кліку файл відкривається через протокол file:// як звичайний файл, тому PHP-код не виконується. Адреса localhost надсилає запит до вебсервера, який спочатку виконує PHP-код і відправляє браузеру вже готовий результат у вигляді HTML.
4. За що відповідає конструкція echo у PHP?
Конструкція echo використовується для виведення тексту, змінних або HTML-тегів у вихідний потік сторінки.
5. Яку інформацію виводить функція phpinfo() і для чого вона може знадобитись?
Функція phpinfo() виводить детальну інформацію про налаштування PHP, версію, підключені модулі та змінні середовища. Вона потрібна для перевірки конфігурації сервера.
